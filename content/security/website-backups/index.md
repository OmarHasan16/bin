## **Product FAQs**

### **What is CodeGuard?**
CodeGuard is a cloud-based website backup service that ensures secure backup storage and protects customer data using AES-256 encryption. Annual security audits ensure data integrity.

### **Does CodeGuard offer a Money-Back Guarantee?**
Yes, CodeGuard provides a **30-day money-back guarantee** on all plans.

### **Can I switch between CodeGuard plans?**
Yes, you can upgrade or downgrade your plan at any time.

### **Can I backup multiple websites?**
Yes, depending on the plan you choose, you can backup up to **100 websites**.

### **Where is my website backup stored?**
All backups are stored securely in the cloud with **AES-256 encryption**.

### **Do I need to set up cron jobs for backups?**
No, CodeGuard handles backups automatically without the need for cron jobs.

### **What credentials are required for CodeGuard Website Backup?**
You will need your website's FTP/SFTP credentials or direct database access to set up automated backups.
